# 题库管理端新版接口对接

管理端已切换到冻结契约中的新版页面和接口。页面入口为：

- `/admin/quiz`：分类树、题目列表、状态操作、单题统计。
- `/admin/quiz/imports`：CSV/JSON 文件任务提交、任务轮询和错误报告。
- `/admin/quiz/audit-logs`：审计日志分页和详情。

路径以 `Backend/docs/quiz/OpenAPI契约.md` 和实际路由装配为准，使用 `/admin/quiz/...`；部署层由 Admin Nginx 将该前缀代理到后端。部分需求示例写成 `/api/admin/...` 时，不应在本项目再额外拼接 `/api`。

前端只注册以上新版页面；旧 `/admin/quiz/import` 页面和旧导入/批量删除接口不再重定向、调用或兼容。

## 联调门禁

前端代码可以先合入，但不要在后端阶段二 `QB-06` 至 `QB-12` 完成前切换生产联调。正式联调前需要通过后端管理/导入集成测试，并确认以下路径已由旧运行时实现替换：

`/admin/quiz/categories`、`/admin/quiz/questions`、`/admin/quiz/questions/{question_id}/publish`、`/admin/quiz/questions/{question_id}/disable`、`/admin/quiz/questions/{question_id}/restore`、批量发布/停用、题目统计、导入任务和审计日志路径。

## 前端约束

- 所有写请求携带服务端返回的最新 `lock_version`。`409/40201` 只刷新数据，不静默重试，并保留当前编辑输入。
- 分类状态使用 `active`/`disabled`；题目状态使用 `draft`/`published`/`disabled`。
- 多选答案始终发送数组，例如 `['A', 'C']`；选项键只允许连续的 `A-D`。判断题固定 `A=正确`、`B=错误`。
- 创建题目不会发送 `category_name` 或其它契约外字段；草稿创建后必须单独发布。
- 删除草稿逐题调用 `DELETE .../{question_id}` 并在 JSON body 中携带 `lock_version`。已发布过的题目不可物理删除。
- 题目列表将删除草稿与批量停用已发布题目拆成两个明确操作；批量发布/停用遇到任何选中项不合格时不发送部分请求，并展示逐题原因。
- 发布前在页面校验解析、题型对应的选项数量/键和答案形状；服务端校验仍是最终依据。
- CSV/JSON 导入只创建草稿，分类路径必须已经存在；导入响应中的任务 ID 用于轮询，只有报告可用且未过期时才请求临时地址。

权限使用 `quiz:list`、`quiz:write`、`quiz:import`。导入任务页同时展示上传和任务列表，因此要求 `quiz:list + quiz:import`。
