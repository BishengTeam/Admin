# 题库管理端新版接口对接

> 2026-08-13 状态：当前唯一任务清单为 `Backend/docs/quiz/题库模块全链路开发Todo.md`。冻结契约共 52 个 operation（用户端 22、管理端 30）；三端 manifest 和 Admin 严格类型已同步，真实 Backend/OSS/Worker 联调仍按 QF-28～QF-35 及发布门禁跟踪。

管理端服务已接入全部 30 个管理 operation。当前页面入口为：

- `/admin/quiz/questions`：统一分类/题目工作台；左侧分类树负责分类管理，右侧按所选分类及后代筛选题目，筛选状态写入 URL。旧 `/admin/quiz/categories` 重定向到此页面。
- 工单「处理」跳转：`/admin/quiz/questions?question_id=xxx&include_deleted=true` 会按题目 ID 精确定位（后端 `GET /admin/quiz/questions` 支持可选 `question_id` 过滤），自动选中所属题库与知识点并打开修订历史；客服工单页的【题目反馈】工单点击「处理」即走此链路，同时工单标记为处理中。
- `/admin/quiz/imports`：CSV/JSON 文件任务提交、任务轮询、页内错误明细和缺失分类确认。
- `/admin/quiz/audit-logs`：审计日志分页和详情。
- `/admin/quiz/tasks`：读取健康/就绪探针中的题库后台任务指标。
- `/admin/quiz/stats`：题库聚合统计页，提供总览和单题分页筛选。

路径以 `Backend/docs/quiz/OpenAPI契约.md` 和实际路由装配为准，使用 `/admin/quiz/...`；部署层由 Admin Nginx 将该前缀代理到后端。部分需求示例写成 `/api/admin/...` 时，不应在本项目再额外拼接 `/api`。

前端不调用旧 `/admin/quiz/import`、旧导入或 `batch-delete` 接口。任务监控属于 OPS 辅助页，不替代分类、题目、导入、聚合统计和审计五个逻辑页面。

## 前端约束

- 所有写请求携带服务端返回的最新 `lock_version`。`409/40201` 只刷新数据，不静默重试，并保留当前编辑输入。
- 分类状态使用 `active`/`disabled`；题目状态使用 `draft`/`published`/`disabled`。
- 多选答案始终发送数组，例如 `['A', 'C']`；选项键只允许连续的 `A-D`。判断题固定 `A=正确`、`B=错误`。
- 创建题目不会发送 `category_name` 或其它契约外字段；草稿创建后必须单独发布。
- 删除草稿逐题调用 `DELETE .../{question_id}` 并在 JSON body 中携带 `lock_version`。已发布过的题目不可物理删除。
- 题目列表只对当前页明确勾选的 1～100 题执行原子批量发布/停用；单题仍可删除从未发布草稿。遇到任何选中项不合格时不发送部分请求，并展示逐题原因。
- 发布前在页面校验解析、题型对应的选项数量/键和答案形状；服务端校验仍是最终依据。
- CSV/JSON 导入只创建草稿；缺失分类不会静默创建，而是进入 `awaiting_category_confirmation`。确认后分类与全部草稿题在同一事务创建，任一错误全部回滚。
- 导入任务响应严格接收版本、影响、确认、执行保护及生命周期字段；错误明细不展示题干、选项、答案或原始值。

## 运维监控

后台任务状态页为 `/admin/quiz/tasks`，读取后端 `/health`、`/ready` 的 `details.quiz_tasks`，展示导入、考试超时、统计聚合和 OSS 清理四类处理器。`source` 中只有 `redis` 表示独立 Worker 共享指标，`process` 是开发期 Web 内嵌模式，`disabled/unavailable` 必须提示异常；`signals` 提供 Worker 新鲜度、总积压/失败、卡死处理器、统计滞后、考试超时和 OSS 清理积压。Web 进程内存数据不能作为生产验收依据。该页属于只读运维能力，不计入 30 个 `/admin/quiz/*` 管理 operation；Admin 业务请求不得把路径改写成 `/api/admin/quiz/*`。

权限使用 `quiz:list`、`quiz:write`、`quiz:import`。导入任务页同时展示上传和任务列表，因此要求 `quiz:list + quiz:import`。
