# 后台认证管理接口流程

认证管理页只调用 `/admin/certifications` 系列接口，不再单独调用 `/admin/prices`。

## 页面加载

```http
GET /admin/certifications?page=1&page_size=20&keyword=
Authorization: Bearer <admin_token>
```

权限：`content:list`

返回字段：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "items": [
      {
        "id": 1,
        "code": "H3C-NE",
        "vendor": "H3C",
        "normal_price": 480000,
        "student_price": 380000,
        "is_active": true,
        "created_at": "...",
        "updated_at": "..."
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  }
}
```

## 新增认证

```http
POST /admin/certifications
Authorization: Bearer <admin_token>
Content-Type: application/json
```

权限：`content:write`

请求体：

```json
{
  "code": "H3C-NE",
  "vendor": "H3C",
  "normal_price": 480000,
  "student_price": 380000,
  "is_active": true
}
```

后端同时创建 `certification` 认证记录、`price_config` normal 价格和 `price_config` student 价格。

## 编辑认证

```http
PUT /admin/certifications/{cert_id}
Authorization: Bearer <admin_token>
Content-Type: application/json
```

权限：`content:write`

请求体支持部分更新：

```json
{
  "code": "H3C-SE",
  "vendor": "H3C",
  "normal_price": 580000,
  "student_price": 480000,
  "is_active": true
}
```

如果修改 `code`，后端同步更新对应 `price_config.product_type`。

## 下架认证

```http
DELETE /admin/certifications/{cert_id}
Authorization: Bearer <admin_token>
```

权限：`content:write`

作用：`certification.is_active = false`。价格配置保留；下单前会校验认证是否上架。

## 导出

```http
GET /admin/certifications/export
Authorization: Bearer <admin_token>
```

权限：`content:read`

导出字段：

```text
ID
认证代码
厂商
普通价格
学生价格
上架状态
创建时间
更新时间
```

## 交互流程

- 进入页面：拉取认证列表。
- 新增：提交 `POST /admin/certifications`，成功后刷新列表。
- 编辑：使用当前列表行数据填充弹窗，提交 `PUT /admin/certifications/{cert_id}`，成功后刷新列表。
- 下架：提交 `DELETE /admin/certifications/{cert_id}`，成功后刷新列表。
- 搜索和分页：重新拉取认证列表。

当前不需要单独详情接口；编辑弹窗直接使用列表行数据。

## 价格接口

`/admin/prices` 短期保留为内部接口，前端不展示独立入口。认证管理负责定义认证代码、厂商、价格和上架状态；各认证专用接口负责报名字段、查价、库存锁定和订单创建。
